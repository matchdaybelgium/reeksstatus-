Matchday Belgium bijwerken

Haalt de nieuwe wedstrijdbladen op bij RBFA (vanuit jouw browser) en zet een nieuw data.js op GitHub. De site is 1 à 2 minuten later bijgewerkt.

1. GitHub-sleutel (eenmalig)

  1. Open github.com → nieuwe fine-grained token.
  2. Naam: reeksstats, vervaldatum naar keuze.
  3. Repository access: Only select repositories → reeksstatus-.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Klik Generate token en plak hem hieronder.

De sleutel blijft in deze browser en gaat alleen naar GitHub.

2. Bijwerken

De eerste keer in deze browser duurt het ongeveer 70 minuten (RBFA laat 200 verzoeken per minuut toe). Daarna onthoudt de browser de oude matchen en duurt het enkele minuten. Laat dit tabblad open staan.

Klaar om te starten.
